카카오 카페 검색 API 테스트

기존 카페 찾기 HTML에 저장된 카카오 JavaScript 키를 기본값으로 사용합니다. 실제 카카오 지도 SDK의 주소 검색·장소 키워드 검색 결과를 확인하는 독립 테스트 페이지입니다.

연결 전입니다. API 연결 버튼을 눌러주세요.
중요: 이 페이지를 휴대폰이나 PC에서 직접 열 때 file:// 방식은 사용할 수 없습니다. 기존 카페 찾기 페이지와 동일한 등록 도메인에서 실행하거나, 카카오 개발자 콘솔에 등록된 localhost 주소의 웹 서버(Live Server 등)에서 실행해주세요.

1. 중심지 후보 확인

주소 검색 결과와 장소 검색 결과를 모두 보여줍니다. 원하는 후보의 ‘이 좌표 선택’을 누른 뒤 검색 테스트를 진행하세요.

API 연결 후 후보가 표시됩니다.

2. 검색어별 결과 비교

선택한 중심 좌표와 반경을 기준으로 다음 검색어를 각각 조회합니다. 각 검색은 최대 45개까지 확인합니다.

선택된 중심 좌표: 없음

검색 결과가 여기에 표시됩니다.
