NCP Maps · CafeFinder 테스트

지도·주소 좌표 변환·네이버 지역 검색 결과의 반경 필터링을 별도로 검증합니다.

1. NCP Maps 연결

NCP 콘솔에서 Maps 애플리케이션에 Web Dynamic Map을 활성화하고, 서비스 URL에 현재 페이지의 도메인을 등록해야 합니다. Geocoding도 함께 신청해야 주소 검색이 동작합니다.

아직 지도가 연결되지 않았습니다.

2. 중심지 주소 검색

Geocoding 결과의 좌표를 지도 중심으로 설정합니다.

지도 연결 후 테스트할 수 있습니다.

3. 네이버 지역 검색 테스트

지역 검색 API는 현재 요청당 최대 5개 결과를 제공합니다. 브라우저에 Client Secret을 직접 입력하지 않도록 프록시 방식으로 구성했습니다.

장소 검색은 프록시 서버 연결 후 테스트할 수 있습니다.
중요한 제한
네이버 지역 검색은 지도 화면의 현재 위치 주변을 검색하는 반경 검색 API가 아닙니다. 검색어 관련 결과 중 최대 5개를 받아 좌표로 반경을 필터링하는 테스트입니다. 따라서 2km·5km 안의 전체 카페 목록을 보장하지 않습니다.
