카카오맵 주소 매칭 도구

주소를 여러 방식으로 재검색해 최대한 가까운 도로명·지번 주소를 찾아 정리합니다.

카카오맵 API 연결 설정

기본 JavaScript 키가 입력되어 있습니다. 연결 진단에 실패할 때만 새 키로 교체해 주세요.

연결 확인 전
카카오 개발자 콘솔에서 키 발급 ↗
JavaScript 키 및 API 진단

브라우저 JavaScript 실행, 엑셀 라이브러리, 카카오 SDK, 주소 검색 API를 실제 요청으로 확인합니다.

연결이 실패하면 카카오 개발자 콘솔에서 JavaScript 키를 새로 발급하고, 현재 실행 주소(localhost 또는 배포 도메인)를 플랫폼의 웹 도메인에 등록한 뒤 새 키를 입력하세요.
첫 번째 시트의 첫 행을 열 제목으로 읽습니다.
검색은 원문 주소 → 공백·기호 정리 주소 → 카카오 장소 검색 순서로 확장합니다. 입력 주소의 상세 수준에 맞춰 후보를 제한하며, 선택이 필요한 복수 후보만 확인 필요로 표시합니다. 카카오 개발자 콘솔에 현재 접속 주소를 웹 도메인으로 등록해야 하며, localhost 실행을 권장합니다.
