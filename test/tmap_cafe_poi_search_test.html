TMAP 카페 검색 테스트

카카오 Local API에서 찾지 못한 카페를 TMAP 장소(POI) 통합 검색으로 찾을 수 있는지 확인하는 독립 테스트 페이지입니다.

키는 이 페이지에서 API 요청을 보낼 때만 사용하며 브라우저 저장소에는 저장하지 않습니다.
상호명이나 장소명을 입력하세요. 검색어에 '카페'를 포함한 검색과 상호명만 입력한 검색을 각각 비교해 볼 수 있습니다.
참고: TMAP POI 검색은 카페 업종만 전수 조회하는 API가 아니라, 입력한 검색어와 일치하는 장소를 찾는 통합 검색입니다. 따라서 결과가 없더라도 TMAP에 해당 카페 데이터가 전혀 없다고 단정할 수는 없습니다. 브라우저에서 직접 호출하므로 네트워크/CORS 정책에 따라 요청이 차단될 수도 있습니다.
AppKey와 검색어를 입력한 뒤 검색을 시작하세요.
